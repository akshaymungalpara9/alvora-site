# GEO prompt panel and recording sheet

Fixed monthly panel for tracking how AI answer engines talk about Alvora Diamonds and its category. Run once a month, record every prompt, log the results in the sheet at the bottom. Do not edit prompts between runs: trend only means something if the questions stay fixed.

## How to run

1. Run all 36 prompts, unmodified, in one session per engine tracked (note the engine and model in the sheet).
2. Use a fresh conversation per prompt so answers do not influence each other.
3. Record the fields below for each prompt. No cherry-picking: every prompt gets a row, good answer or bad.
4. Summarise: mention rate per group, citation rate (an Alvora URL used as a source), position where listed, and the three worst inaccuracies. File the summary in seo/LOG.md.

## Recording fields

Date | Engine/model | Prompt ID | Alvora mentioned (Y/N) | Position if listed | Alvora URL cited | Competitors named | Accuracy notes | Action needed
